# 🤖 AI Business Analyzer

### Transforming Business Data into Smart Insights and Decisions

## 📌 Project Overview

AI Business Analyzer is an AI-powered business data analysis system developed using **n8n Workflow Automation, OpenAI, Google Sheets, and Gmail**.

It allows users to submit a Google Sheets URL through a chat interface. The AI Agent analyzes the sales data, generates meaningful insights, and automatically sends the complete analysis report through Gmail.

## 🎯 Objectives

- Automate business data analysis.
- Reduce manual data processing.
- Generate meaningful sales insights.
- Provide AI-powered business recommendations.
- Automatically deliver reports through email.

## ✨ Features

- Interactive AI Chat Interface.
- Google Sheets Data Integration.
- Automated Sales Data Analysis.
- AI-Powered Insights Generation.
- Sales Trends and Performance Analysis.
- Automated Gmail Report Delivery.
- Chat Memory for conversation context.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| n8n | Workflow Automation |
| OpenAI GPT-5 Mini | AI Analysis |
| Google Sheets | Sales Data Source |
| Gmail | Email Report Delivery |
| AI Agent | Data Analysis |
| Simple Memory | Conversation Context |

## ⚙️ System Workflow

1. User enters a Google Sheets URL in the chat interface.
2. AI Agent receives the user's request.
3. Google Sheets retrieves sales records.
4. AI analyzes the collected data.
5. System generates a detailed sales report.
6. Gmail sends the report to the specified email address.
7. Final analysis is displayed in the chat interface.

## 📊 Analysis Includes

- Total Revenue.
- Total Sales Quantity.
- Total Discounts.
- Top-Selling Products.
- Lowest Revenue Products.
- Sales Trends.
- Business Insights.
- Actionable Recommendations.

## 🚀 Installation and Setup

1. Install or access n8n.
2. Import the downloaded `My workflow.json` file into n8n.
3. Configure OpenAI credentials.
4. Connect your Google Sheets account.
5. Connect your Gmail account.
6. Activate the workflow.
7. Open the chat interface and submit a Google Sheets URL.
